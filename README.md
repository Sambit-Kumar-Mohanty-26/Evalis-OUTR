# Evalis

Evalis is a modern full-stack web application initialized with a robust structure.

## Overview

This repository is split into two main directories:

- `frontend/` - A Next.js frontend application.
- `backend/` - A Node.js backend application.

## Prerequisites
- Node.js (v18 or higher)
- npm or yarn

## Quick Start

### Frontend
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Backend
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
